# KTK

## Приложение для Канского ТК

> **Форк** официального проекта [Ethosa/KTC](https://github.com/Ethosa/KTC) с редизайном и исправлениями.

**Автор форка:** QkartBismuth

</div>

Приложение позволяет просматривать расписание для студентов и преподавателей, новости и фотогалерею.

Вы можете помочь развитию проекта, создав `issue`, если нашли баг/ошибку или у Вас какая-то идея.

## Изменения в форке

- **Переименован в KTK** — приложение, проект и иконка теперь называются KTK; новая иконка в фирменном цвете с логотипом «КТК».
- **Смена пакета на `com.qkartbismuth.ktc`** — исходники, манифест и конфигурация сборки перенесены в новый пакет.
- **Новая вкладка «Кабинеты»** в режиме преподавателя: список всех кабинетов колледжа с количеством занятий на сегодня; по нажатию раскрываются занятия дня — время, группа, преподаватель и предмет. Расписание собирается из данных всех групп филиала и кэшируется в памяти.
- **Полный редизайн интерфейса в стиле Material 3** — переработанные экраны филиалов, курсов и преподавателей: новые карточки, чипы, тулбары, кнопка выбора темы.
- **Исправлено перекрытие расписания заголовком** — заголовок и тулбар больше не перекрывают список уроков.
- **Исправлено задвоение уроков** — быстрый скролл больше не накапливает дубликаты занятий в карточках дней.
- **Исправлено отображение отменённых занятий** — занятия с флагом `cancelled` больше не показываются как обычные: теперь они выводятся серым цветом, с зачёркнутым названием и меткой «Отменено».
- **Исправлена OLED-тема** — тёмная/OLED тема корректно применяется до создания экранов.
- **Локализация статусов занятий** — добавлены строки «Отменено»/«Cancelled» для русского и английского языков.
